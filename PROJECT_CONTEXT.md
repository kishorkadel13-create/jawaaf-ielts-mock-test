# Jawaaf IELTS Lab

## Tech Stack
- React (Vite)
- Node.js + Express
- Supabase
- Tailwind CSS
- Zustand
- React Router

## Main Modules
- Reading Practice
- Listening Practice
- Writing Practice
- Full Mock Tests
- Recorded Courses
- Student Dashboard
- Admin Dashboard

## Design System
- Primary: #294b77
- Accent: #ef5f55
- Mobile-first responsive
- No horizontal scroll
- Premium SaaS style

## Important Rules
- Listening uses one continuous audio file.
- Audio cannot pause/forward/rewind.
- Writing has Task 1 + Task 2 with shared 60 min timer.
- Internal copy/paste only in writing editor.
- Practice tests are section-wise.
- Mock tests are full IELTS tests.
